### 1.3 这一轮顺手抓到的坑（不是 T-6 要测的功能，但值得记）

写验收测试时踩到：**手写 `ButtonData` 忘了置 `hoverInheritsNormal = false`**，
构造按钮时的 `Normalize()` 就会拿 normal 把 hover / onclicked **整个覆盖**。
症状极具迷惑性——`GetState()` 照常说 `Hover`、状态机照常工作，但**外观一个字节都没变**，
表现是"动画一动不动"。已记进 `AGENTS.md` §6。

> 生成器生成的代码不会有这个问题（它显式写了这两个标志），
> 所以**手写配置**的人要特别小心——这条也写进了 `UsageReport.md` 的排错表。

## 3. 已知"没做"的（不用测，免得白费劲）

- **第二档形状**（`capsule` / `ring` / `line` / `polygon`）：报"尚未实现"；
- **缓动曲线**：一律 linear（配置里没有 `easing` 字段）；
- **布局通道动画**（改尺寸那种）：没有配置字段；
- **文字渲染**：画的是占位方块（`text` 段字段能配、也会提醒）；
- **`img` / `svg` 外观**：生成器收下并提醒，运行期不画；
- **顶点缓存 / 合批**：没有——目前一节点一次 `SDL_RenderGeometry`。
